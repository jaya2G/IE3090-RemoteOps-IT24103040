# RemoteOps Project Reflection

## Overview

The RemoteOps project provided practical experience in developing and testing a client-server application using C in a Linux environment.

## Technical Learning

During the development process, I gained experience with:

- Linux command-line operations
- C programming
- Client-server communication
- Socket-based communication
- Authentication
- File transfer
- Process management
- System information retrieval
- Remote command execution
- Monitoring
- Logging
- Git and GitHub

## Testing Experience

The system was tested using different RemoteOps operations.

Authentication was tested using both successful and failed attempts.

The SYSINFO command was tested to retrieve system information.

The LISTPROC command was tested to retrieve running processes.

The EXEC command was tested using commands such as `hostname`.

The PUT and GET operations were tested using a sample file. The log records show successful file transfer operations.

The monitoring functionality was also tested using MONITOR START and MONITOR STOP.

## Challenges

One of the main challenges was understanding how the different client-server operations work together. Testing each command individually helped identify problems and verify the expected behaviour.

Git and GitHub were also used throughout the development process to maintain the project history.

## Lessons Learned

The project improved my understanding of:

1. Linux-based development
2. C client-server programming
3. Network communication
4. File handling
5. System monitoring
6. Authentication
7. Testing and debugging
8. Version control using Git

## Conclusion

The RemoteOps project provided practical experience in developing a network-based application and managing the development process using Git and GitHub. Incremental testing and version control helped maintain the project and document its development history.
